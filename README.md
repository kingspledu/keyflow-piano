# KEYFLOW

Web MIDI 피아노 리듬 게임. 작은 별, 환희의 송가, 캐논 연습 편곡을 제공합니다.

Chrome/Edge의 HTTPS 또는 localhost에서 실행하세요. MIDI 연결 버튼으로 접근을 허용하고 연습을 시작하세요. 키보드 A–K 또는 화면 건반도 지원합니다. 음역 C4–C6. 재생 속도, 입력 보정, 자동 데모, 점수와 최고 기록을 제공합니다. MIDI 파일 가져오기와 서스테인 페달 판정은 지원하지 않습니다.

로컬 실행: 이 디렉터리에서 `python -m http.server 8080` 실행 후 http://localhost:8080 방문.

하드웨어 MIDI 검증은 실제 악기 연결이 필요합니다.
